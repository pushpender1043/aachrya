## 🎩 Introduction

**Aachrya** is a full-stack, comprehensive platform designed for all spiritual and astrological needs. It provides users with the ability to book live consultations with expert astrologers, purchase authentic spiritual products (like Gemstones and Rudraksha), book online Poojas, and generate detailed Kundlis. The platform also features an innovative AI Astrology Bot for instant cosmic guidance.

## ✨ Key Features

| Category | Features |
| :--- | :--- |
| **🗣️ Consultations** | Book and conduct live video/audio sessions with astrologers using **WebRTC**. |
| **🛍️ E-Commerce Store** | Browse and purchase authentic Gemstones, Yantras, and Rudraksha. |
| **🕉️ Pooja Bookings** | Schedule and manage online or offline spiritual ceremonies. |
| **🤖 AI Astrology Bot** | Get instant, AI-driven astrological insights and horoscope readings. |
| **📊 Calculators** | Detailed Kundli generation, Daily Horoscopes, and Panchang details. |
| **👨‍💻 Admin Dashboard** | Complete management system for Users, Astrologers, Orders, and Bookings. |

## 🛠️ The Tech Stack

- **Frontend:** `React.js` + `Vite` + `TypeScript`
- **Styling:** `Tailwind CSS` + `Shadcn UI`
- **Backend & Database:** `Supabase` (PostgreSQL, Auth, Edge Functions)
- **Real-time Communication:** `WebRTC` (For Live Consultations)
- **State Management & Routing:** `React Router`
